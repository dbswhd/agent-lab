## Hypotheses

- H1: The Playwright Vite server starts the managed API even though this spec intercepts every API request, so a worktree-local `.venv` is incorrectly required before the browser can start.

## Root cause

- Mechanism: Playwright starts Vite through `web/playwright.config.ts`. Vite's `ensureDevApi()` runs unless `VITE_SKIP_API` is set, so a fixture-only E2E suite fails before browser launch when the worktree has no local `.venv`. Prior runs reused an existing Vite server and masked this precondition.
- Toggle proof: without `VITE_SKIP_API`, exact command exits 1 on missing `.venv`; with it, exact command passes 5/5.
- Fix scope: Playwright webServer command only; preserve browser and mocked API execution.

### Green phase
